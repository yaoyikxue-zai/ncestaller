脚本支持一键部署,git好仓库后执行以下命令:
```bash
cd ncetaller/Pkg/ && chmod 755 ncestaller && ./ncestaller installer ncestaller 
```
同样也支持 
```bash
ncestaller uninstall<br>
```

更多命令可以在安装后执行:
```bash
ncestaller -h 
```
或者
```bash
ncestaller --helps
```
